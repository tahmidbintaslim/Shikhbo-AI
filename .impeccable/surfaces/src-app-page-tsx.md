# Surface brief: Shikhbo home, centre tutor and owner dashboard

Scope: `/` (Persuade, with the working tutor in it), `/c/[slug]` and `/c/[slug]/dashboard` (Operate). Audience and product truth are in PRODUCT.md.

- Home: a parent or child must understand in seconds that they can ask a homework question now, in Bangla, and get steps. The action is the question box itself. No testimonials, prices or user counts exist; none are shown.
- Centre pages: the centre's name leads; the student asks, the owner reads the week and adds notes.

## Direction contract

THESIS: The site is one page of a school exercise copy (khata). The question is written on its lines and the answer comes back as worked steps with the teacher's page reference. It refuses the edtech landing page of headline, button and three feature cards.

OWN-WORLD: White ruled paper: pale blue horizontal rules on a fixed line height, one red margin line down the left, ballpoint-blue ink for what the student writes and for actions, teacher's red ink only for marks (tick, page reference, errors), pencil grey for secondary text. Hand-ruled boxes with square corners; no cards, shadows, glass or gradients. Bangla text set in Hind Siliguri, sitting on the rules.

STORY: "This is my copy. I write the question, the teacher works it out step by step, and tells me which page it is from."

FIRST VIEWPORT: Copy header line (name left, class and language pickers right, as the label fields on a khata's cover). Below it the ruled page: a large heading on the lines, then the question line with the send action at the right edge; the chat is the page itself, not a box beside a hero. On desktop the right-hand page carries the subjects as an index list.

SIGNATURE INTERACTION: an answer arrives line by line onto the rules, and the red page reference is written last.
